# Estevão Lange — Site institucional

Site estático pronto para publicar. Inclui HTML, CSS, JavaScript, fontes locais, fotografias e vídeo otimizado.

## Publicar no GitHub Pages

1. Crie ou abra o repositório no GitHub.
2. Envie todo o conteúdo desta pasta, mantendo `index.html` na raiz e a pasta `assets` com seus arquivos. Extraia o ZIP antes de enviar; não envie apenas o ZIP.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, a branch `main` e a pasta **/(root)**.
4. Salve e aguarde o GitHub disponibilizar o endereço do site.

Não é necessário instalar dependências nem executar build.

## Visualização local

Execute `python3 -m http.server 4173` nesta pasta e abra `http://localhost:4173`.
